# **What is mona.nvim?**


- A  Neovim plugin


- A set of  `elixir`-focused plugin extensions and configuration


- Written in  `lua`


- Designed to work alongside and compliment existing  LSP plugins


- Aims to be generic and open for customisation
    - ...but favours my own particular workflow

- Prefer naive, possibly ugly solutions over more technically sound, cleaner alternatives


- Compatablity


- Proscriptive


- Specialised


- Integrate with _best in class_, popular  Neovim plugins


- Little environment configuration
